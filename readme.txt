HOW TO COMPILE:
1. Open SupermarketPOS.sln in Visual Studio
2. Build → Build Solution (Ctrl+Shift+B)
3. Target: x64/Debug

HOW TO RUN:
1. Run SupermarketPOS.exe
2. Login credentials:
   - Admin: admin / admin123
   - Cashier: cashier01 / cashier123
   - Manager: manager01 / manager123

REQUIREMENTS:
- Windows OS
- SQL Server LocalDB installed

FEATURES IMPLEMENTED:
- Secure role-based login (Admin/Cashier)
- Process sales with barcode scanning
- Automatic VAT calculation (15%)
- Real-time stock updates after each sale
- Process returns with manager approval (>R100)
- Low stock alerts after sales
- Product management (Add/Update/Delete)
- User management (Add/Update/Disable/Reset password)
- Sales reports with date filtering and CSV export

NOTES:
- Database: SupermarketPOS on (localdb)\MSSQLLocalDB
- Tables created automatically on first run
- Data seeded from users.txt and products.txt
